## Notes for Development

1. **Legacy Achievement Rebalancing Required:** Currently 75% of events have legacy achievements. This should be reduced to 5-10% for better balance. Legacy should mark truly significant historical moments, not routine decisions.

2. **Decision Threshold System:** Not yet utilized. This is a powerful mechanic for tracking repeated player behavior and triggering consequences (e.g., repeated lethal force triggers revolution).

3. **Storyline Density:** Most storylines need 8-12 more events each to feel complete with proper branching and consequences.

4. **Conditional Event Gap:** Only 7 events have conditions. More sophisticated gating would add depth (e.g., events that only appear after certain years, or require specific combinations of metrics).

5. **Weight Tuning:** Consider adding some rare (weight 1-2) and critical (weight 13+) events for variety in pacing.
