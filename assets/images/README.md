# Game Assets

This directory contains the visual assets for *The Oligarch's Gambit*.

## Directory Structure
*   `events/` - Unique images for specific event cards. Filename must match event ID (e.g., `dacha_summit.png`).
*   `storylines/` - Cover images for storylines. Filename must match storyline ID (e.g., `early-game-agenda.png`). Used as a fallback for events in that storyline.
*   `*.png` - Legacy/General assets (being migrated or used as defaults).

## Asset Requirements
See `VISUAL_DESIGN.md` in the project root for full specifications.
*   **Resolution:** 512x716 px
*   **Format:** PNG or WebP
*   **Style:** "Gilded Decay" - Dark, political thriller, oil painting texture.
